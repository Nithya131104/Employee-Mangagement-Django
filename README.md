Features:
Add Employees: A specialized form to input employee details like Name,ID,Department, and salary.
View Details: A clean table interface displaying all registered employees.
Update/Delete: Functionality to modify exisiting employee information or remove records from the system.
Backend Validation: Powered by Django models and forms

Tech Stack:
Language: Python
Framework: Django 5.2.7
Frontend: HTML5,CSS3
Database: SQLite3

Project Structure:
Employee/:Contains the main app logic including models.py,views.py,and urls.py.
templates/:Houses the HTML files for the adding page and details view.
manage.py: The entry point for running the Django development server.
